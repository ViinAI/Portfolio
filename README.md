# Vinay Kumar — Senior AI Engineer Portfolio

A minimalist, high-performance developer portfolio built with Next.js 16 App Router, React 19, and Tailwind CSS. Strictly content-aligned with verified engineering achievements in agent execution engines, gVisor sandboxing, and MCP platform tooling.

## 🚀 Key Technical Highlights

- **Multi-Page Architecture**: Fast, client-side routing across `/experience`, `/products`, `/skills`, and `/contact`.
- **Pure White Aesthetic System**: Clinical, typography-driven UI hierarchy with high-contrast, border-scoped components inspired by modern minimalist design.
- **Enterprise Engineering Focus**: Detailed breakdowns of production agent execution engines, microVM isolation, Model Context Protocol (MCP) servers, and RAG pipelines.

## 🛠️ Built With

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Deployment**: Vercel

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/ViinAI/Portfolio.git

# Navigate into the portfolio directory
cd portfolio-web

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001`) with your browser to see the result.
